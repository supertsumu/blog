## Rayquaza - 50 points - Misc

<center><img src="/rayquaza.png" width="63%" height="63%"></center>

In this challenge, we were given the file “1337Pikachu”. Using the Linux “file” command tells us that we are dealing with a Game Boy Advance ROM / GBA file.

<center><img src="/filerayquaza.png"></center>

After spending about an hour trying different Game Boy Advance emulators, I got to boot the ROM using [VisualBoyAdvance](https://www.emulator-zone.com/doc.php/gba/vboyadvance.html) after giving the file a .gba file extension:

<center><img src="/pokemonopening.png" width="90%" height="90%"></center>
